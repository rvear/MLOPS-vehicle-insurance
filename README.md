# 🚗 Vehicle Insurance MLOps Pipeline

An end-to-end MLOps project for managing and deploying a **Vehicle Insurance Prediction Pipeline** using modern cloud-native tools and automation workflows.  
This project demonstrates how real-world ML systems are built, validated, deployed, and monitored using industry-standard technologies.

---

## 📌 Project Overview

This project covers the complete lifecycle of a Machine Learning application:

- Data Ingestion from MongoDB
- Data Validation & Transformation
- Model Training & Evaluation
- AWS S3 Model Storage
- Docker Containerization
- CI/CD with GitHub Actions
- Deployment on AWS EC2

The goal of this project is to showcase practical MLOps skills and production-level ML workflow implementation.
